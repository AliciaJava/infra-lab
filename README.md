# infra-lab

Laboratorio personal de infraestructura como código y administración de sistemas.

## Estructura

- `ansible/`: inventarios, playbooks y roles.
- `libvirt/`: redes, máquinas virtuales y cloud-init.
- `networking/`: prácticas de VLAN, bonding e iptables.
- `storage/`: prácticas de NFS, iSCSI y Ceph.
- `orchestration/`: pruebas con OpenStack y CloudStack.
- `docs/`: documentación y apuntes.

## Equipo

- Ubuntu 24.04
- 12 GB de RAM
- SSD de 256 GB

No guardar contraseñas, claves privadas ni tokens en este repositorio.
